# railday — Train Booking System

A browser-based train booking project built with **HTML, CSS and JavaScript**. It uses sample trains, schedules, seat availability and fares. It does not contact a railway service, take payment or create a real ticket.

# Main features

- Search sample services by origin, destination, date and number of travellers.
- Sort matching trains by departure, fare or journey duration; filter by class.
- Select a class and seats while observing seeded and previously saved seat occupancy.
- Enter passenger and contact details with built-in form validation.
- See a fare breakdown and save a clearly marked demo record in the browser.
- Review or remove saved demo trips, and print a demo summary.
- Responsive layout, keyboard focus styles, reduced-motion support and print styles.


# Files

- `index.html` — semantic page structure and forms
- `style.css` — responsive visual design
- `script.js` — sample data, interactions, fare logic and browser storage
- `README.md` — setup and concept guide
